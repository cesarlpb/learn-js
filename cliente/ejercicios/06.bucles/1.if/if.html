Bucle If (Si condicional)

El bucle o loop if es un bloque que permite controlar el comportamiento del programa según la evaluación de una condición.

  • if -> si condicional
  • else -> en caso contrario
  • else if -> en otro caso // otra condición


    // solo true:
    if (condición) {
      // lo que sucede en caso de true
    }

    if (condición) {
      // lo que sucede en caso de true
    } else {
      // lo que sucede en caso de false
    }
