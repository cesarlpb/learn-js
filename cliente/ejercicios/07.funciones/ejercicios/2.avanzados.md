1. **Ejercicio 1: Número Harshad**  
   Escribe dos funciones:  
   - Una función auxiliar que calcule la suma de los dígitos de un número entero positivo (utilizando únicamente operaciones matemáticas, sin convertir el número a cadena).  
   - Una función principal que, utilizando la función anterior, determine si el número es divisible por la suma de sus dígitos (es decir, si es un número Harshad).  
   *Pista: Llama a la función de suma de dígitos desde la función principal para obtener el divisor.*

2. **Ejercicio 2: Secuencia de Collatz con contador de pasos**  
   Crea dos funciones:  
   - Una función auxiliar que, dado un número entero positivo, retorne el siguiente término de la secuencia de Collatz (si es par, divídelo entre 2; si es impar, multiplícalo por 3 y súmale 1).  
   - Una función principal que utilice la función auxiliar de forma repetitiva hasta llegar a 1, contando y retornando el número de pasos necesarios para finalizar la secuencia.  
   *Pista: Utiliza un bucle `while` en la función principal que se ejecute mientras el número sea distinto de 1.*

3. **Ejercicio 3: Mínimo Común Múltiplo (MCM) a partir del MCD**  
   Escribe dos funciones:  
   - Una función auxiliar que calcule el Máximo Común Divisor (MCD) de dos números enteros positivos mediante el algoritmo de Euclides (puedes usar bucles o recursión).  
   - Una función principal que, utilizando el MCD obtenido, calcule y retorne el Mínimo Común Múltiplo (MCM) utilizando la fórmula:  
     \[ MCM(a, b) = \frac{a \times b}{MCD(a, b)} \]  
   *Pista: Asegúrate de llamar a la función del MCD dentro de la función que calcula el MCM.*

4. **Ejercicio 4: Conversión de número a otra base**  
   Crea dos funciones:  
   - Una función que valide si la base de conversión proporcionada es un número entero entre 2 y 9.  
   - Una función principal que, si la base es válida, convierta un número entero positivo de base decimal a la base indicada utilizando divisiones sucesivas y acumulando los restos (sin usar métodos de cadena).  
   *Pista: Primero verifica la validez de la base y, luego, realiza la conversión acumulando los restos y luego invirtiendo el orden del resultado.*

5. **Ejercicio 5: Número Armstrong modificado**  
   Escribe dos funciones:  
   - Una función auxiliar que, dado un número entero positivo y una potencia, calcule la suma de cada uno de sus dígitos elevados a dicha potencia (usando operaciones matemáticas para extraer cada dígito).  
   - Una función principal que determine si el número es igual a la suma calculada (por ejemplo, para 153 y potencia 3, se debe verificar si 1³ + 5³ + 3³ es igual a 153).  
   *Pista: Llama a la función auxiliar desde la principal y compara el resultado con el número original para determinar la igualdad.*
