Clases y Objetos

Objetos

Un objeto en programación es una abstracción de una entidad real o virtual que tiene sentido/contexto en nuestra aplicación o programa.

  • En una app de calculadora podemos tener objetos "cálculo", "suma", "resta", ...
  • En una app de una tienda, tiene sentido tener usuarios, carritos, pagos, etc...
  • En una página de un restaurante: comandas, pedidos, órdenes, etc.
  • En nuestras clases (sesiones) podemos tener objetos ejercicios y solucioines.
  • Si trabajamos con una app de vehículos: objeto Coche con datos como matrícula, año, ITV, etc.

    // Pseudocódigo de un objeto:

    Coche {
      "año": 2025,
      "matricula": "ABC 1234",
      "tiene_ITV": true,
      // etc... //
    }
