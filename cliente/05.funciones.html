Funciones


    function nombre(){
      // lógica
  }
Una función es un bloque de código nombrado que se puede ejecutar cuando sea necesario. Hay varias ventajas al usar funciones:
  • Evitamos repetir código
  • Organizamos mejor el código
  • Separación de responsabilidades

Ejemplo: sumar()

  • Esta función "solo" debería hacer la suma de números
  • Inputs: al menos dos números
  • Output: la suma de los números
  • ¿Y si recibe strings? ¿booleans? -> NaN

    // inputs: a y b (number)
    function sumar(a, b){
      return a + b; // -> output (number)
    }
    let resultado = sumar(1, 2); // 3

saludo()


    
    // Función que no tiene parámetros de entrada ni return

    function saludo(){
      let nombre = prompt("¿Cómo te llamas?");
      if(nombre){
        console.log("Hola,", nombre, "!");  
      } else{
        console.log("Hola!");
      }
    }

Variante con return:


    function saludo(){
      let nombre = prompt("¿Cómo te llamas?");
      if(nombre){
        console.log("Hola,", nombre, "!");  
        return "Hola " + nombre;
      } else{
        console.log("Hola!");
        return "Hola";
      }
    }
